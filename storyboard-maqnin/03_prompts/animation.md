Pour corriger : bible.json (bloc animation) ou plans.json, relancer.

Modèle : seedance-1.0 — mode image-to-video — résolution 1080p — ratio 16:9

Contraintes globales (à respecter sur chaque plan) :

- aucun morphing : la sculpture garde exactement sa forme et sa texture
- les fibres bougent comme du fil reel, jamais comme des plumes biologiques
- le fond reste continu, aucun element nouveau n'entre dans le cadre
- premiere frame = image Midjourney validee, fidelite maximale
