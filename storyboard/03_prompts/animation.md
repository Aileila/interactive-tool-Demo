# Document d'exécution animation — Seedance

GENERE par scripts/build_animation.py — ne pas editer a la main.
Pour corriger : bible.json (bloc animation) ou plans.json, relancer.

Modèle : seedance-1.0 — mode image-to-video — résolution 1080p — ratio 16:9

Contraintes globales (à respecter sur chaque plan) :

- aucun morphing : visages et decors gardent leur forme
- les personnages restent fideles a la premiere frame (age, coiffure, costume)
- aucun element nouveau n'entre dans le cadre
- premiere frame = image Midjourney validee, fidelite maximale
